## 这个博客是什么

信息技术、计算机科学有关的笔记。

更新不定期——深度优先于频率。

每一篇文章都写给还没搞懂时的自己：把当初我多希望有人讲给我听的东西讲清楚。

目前的主要内容：

- **[零基础深度学习（The Tiny Learner）](https://raycc.org/series/the-tiny-learner/)** —
  用纯 Python 从零构建一个能真正训练的微型深度学习引擎：优化机制、梯度下降、
  张量、优化器、自动微分。
- **系统与网络实践** — 计算机如何启动（Arch Linux ARM 部署）、什么是路由器
  （Arch Linux 软路由）、什么是透明代理（Linux TProxy）。
- **编程基础** — 什么是程序（HtDP 读后感）、尾递归优化与递归转迭代。
