### 标量、向量、矩阵与张量

首先来看几个概念：

* **标量（Scalar）**：单一数值（如 `3.14` 或 `42`），计算机中用整数/浮点数表示。
* **向量（Vector）**：一个有序的数值序列（数学上称为有序元组），在计算机中通常实现为一维数组。
* **矩阵（Matrix）**：二维数值网格（如 `[[1,2], [3,4]]`），计算机中表示为二维数组。

相信你至少听过向量/矢量这个概念，它常被描述为是一种具有大小（magnitude）和方向（direction）的量，可以用于表示空间中的一个点或方向。但是在计算机科学语境中，我们更关注向量作为数据容器的特性（而非几何意义），因此更多的时候只是把它当作数组对待。因为数组是计算机内存中存储和操作数据最自然、最高效的方式。且硬件（CPU/GPU）对数组运算（向量化运算）有高度优化。有时候数据科学家会把它可视化成方向，但主要目的是理解辅助或成为特定场景下的几何解释。

同理标量是一个单一的、没有方向的数值。理解成一个数值类型即可满足需求；矩阵在线性代数中用于表示线性变换、方程组求解，在这里我们把它理解成一个二维数组。

现在请想象一个更抽象的数据结构，它有一个属性叫做**阶（Rank）**或者秩。当它的阶是0的时候，它就是一个标量；当它的阶是1的时候，它就是一个向量；当它的阶是2的时候，它是一个矩阵；它的阶还可以更高，当阶高于3的时候可能很难在脑中想象成一个高维度空间，理解该结构的这个属性值可以是任意自然数，并存储为高阶数组即可。

这个结构就是一个**张量（tensor）**。在计算机实现层面，张量可定义为标量的递归嵌套结构，首先任何一个实数都可以理解为一个0阶张量，以0阶张量为元素的数组是一个一阶张量，任何一个一一阶张量为元素的数组都是一个二阶张量以此类推……

张量的另一个重要的属性是**形状（shape）**，用来表示该张量在每一阶的元素个数。
比如：$[5.0 \ \ 7.18 \ \ π]$     $[2.0\ 1.0\ 4.0\ 3.0] $都是一阶张量，但是第一个内部有三个零阶张量，第二个内部有有四个零阶张量。我们用Python里的元组符号也就是括号来表示张量的形状，因此这两个一阶张量的形状分别为（3,）和（4,）。

再看几个更难的例子：

|例子|阶|形状
|---|---|---
|$8$| 0 |（）|
|$[[[[8]]]]$|   4|（1, 1, 1, 1）
|$[[[5] [6] [7]] [[8] [9] [0]]]$| 3|（2, 3, 1）
|$[[[8\ 8\ 8]] [[8\ 8\ 8]] [[8\ 8\ 8 ]]] $ | 3  |(3, 1, 3)



仔细观察判断一个张量的阶只要数第一个元素的左括号的数量就可以了，判断形状的话就需要慢慢数每一个阶的元素个数了。这么无聊的事情还是交给计算机来做好了:
```python
from typing import Union, List, Tuple, Callable

# 根据上面的定义，标量要么是整数，要么是浮点数
Scalar = Union[int, float]

# 只要一个列表的子元素都是张量，它本身也是张量
Tensor = Union[Scalar, List['Tensor']]

# 张量要么是标量要么是列表，意味着不是列表的张量就一定是标量
is_scalar = lambda t: not isinstance(t, list)

# 标量的阶为0，如果不是标量就记1，直到数到标量为止
# 如果这些递归代码看不懂建议阅读我之前关于递归的博客
def rank(t: Tensor) -> int:
    return 0 if is_scalar(t) else 1 + rank(t[0])

# 形状同理，标量的形状用空元组表示
# 另这里只数了第一个元素的数量，也就是假设所有同阶元素子元素数量相同
def shape(t: Tensor) -> Tuple[int]:
    return () if is_scalar(t) else (len(t), *shape(t[0]))

# 带入几个数据测试一下
print(rank([1, 2, 3]))
print(rank([[1, 2], [3, 4]]))
print(rank([[[8, 8, 8]],[[8, 8, 8]],[[8, 8, 8]]]))
print(rank([[[[8]]]]))

print(shape([1, 2, 3]))
print(shape([[1, 2], [3, 4]]))
print(shape([[[8, 8, 8]],[[8, 8, 8]],[[8, 8, 8]]]))
print(shape([[[[8]]]]))

# 输出结果：
# 1
# 2
# 3
# 4
# (3,)
# (2, 2)
# (3, 1, 3)
# (1, 1, 1, 1)
```

现在你应该已经对张量有了一定的理解，张量是深度学习模型处理数据的基本形式，用来表示数据、模型参数、中间结果等等，可以想象它的重要性。


### 张量操作

接下来看看对于张量的操作。张量操作有很多，这里我把它们分为三类：

1. **逐元素二元操作（例如加法、乘法）**：将两个同形状张量对应位置的元素进行二元运算。
    >比如向量加法$[a, b] + [c, d] = [a + b, c + d]$ ；哈达玛积 $[a,b] ⊙ [c,d] = [a*c, b*d]$
2. **按元素映射**：将标量→标量函数映射到张量的每个元素。
    >又叫做广播，比如之前实现过的sqr函数；再比如标量乘法$a × [b, c] = [a × b, a × c]$
3. **降维操作**：对张量沿最外层维度经行操作，结果张量的阶降低 1。
    >比如之前用到过的sum函数
4. 其他
    >上一篇文章中实现的点积等等


编程实现：
```python
# 向量加法
def tadd1(t1: Tensor, t2: Tensor) -> Tensor:
    return list(map(lambda a, b: a + b, t1, t2))

# 向量乘法
def tmul1(t1: Tensor, t2: Tensor) -> Tensor:
    return list(map(lambda a, b: a * b, t1, t2))
```
上面两个实现似乎有共同的逻辑，我们可以抽象出一个通用的按元素映射函数，来处理任意阶张量的逐元素操作

```python
# 上面用的是map，下面用列表推导式，可能会让人觉得困惑，实际上逻辑相同。
# 混用是因为Python中map是惰性的，不会直接返回列表，而+，-等操作符不是可以直接传递的函数，代码会更占空间
def tmap(f: Callable[[Scalar], Scalar], t: Tensor) -> Tensor:
    return f(t) if is_scalar(t) else [f(x) for x in t]

# 二元操作逻辑相同
def tmap2(f: Callable[[Scalar, Scalar], Scalar], t: Tensor, u: Tensor) -> Tensor:
    if is_scalar(t) and is_scalar(u):
        return f(t, u)
    else:
        return [f(x, y) for x, y in zip(t, u)]

# 重新实现加法
tadd1 = lambda t, u: tmap2((lambda a, b: a + b), t, u)
# 重新实现乘法
tmul1 = lambda t, u: tmap2((lambda a, b: a * b), t, u)

# 测试
print(tadd1([1, 2, 3], [4, 5, 6]))  # 输出: [5, 7, 9]
print(tmul1([1, 2, 3], [4, 5, 6]))  # 输出: [4, 10, 18]
```
但是如果是矩阵加法或者乘法呢？其实很简单只需要使用两次tmap就可以了
```python
def tadd2(t1: Tensor, t2: Tensor) -> Tensor:
    return tmap2(tadd1, t1, t2)

# 测试
print(tadd2([[1, 2], [3, 4]], [[5, 6], [7, 8]]))  # 输出: [[6, 8], [10, 12]]

```
显然，对于三阶张量，只需在tadd2的基础上再使用一次tmap/tmap2就可以了。但是如果是更多阶张量或者不知道阶数呢？因为张量是一个递归结构，我们可以使用递归来处理任意阶张量的逐元素操作。

```python
# 扩展一元操作到任意阶张量
def ext1(f: Callable):
    def op(t: Tensor):
        if is_scalar(t):
            return f(t)
        else:
            return tmap(ext1(f), t)
    return op
```

但是我们之前实现了很多处理一阶张量的函数了，而上面这个函数只能拓展针对标量的操作，还是需要一个更通用的函数。
```python 
# 首先需要一个辅助函数来判断张量的阶数
def of_rank(n: int, t: Tensor) -> bool:
    return rank(t) == n

def ext1(f: Callable, r: int) -> Callable[[Tensor], Tensor]:
    def op(t: Tensor) -> Tensor:
        if of_rank(r, t):
            return f(t)
        else:
            return tmap(ext1(f, r), t)
    return op

# 现在拓展一些函数
add1 = ext1((lambda x: x + 1), 0)
zero = ext1((lambda _: 0), 0)
sqr = ext1((lambda x: x * x), 0)

tsum = ext1((lambda x: sum(x)), 1)

def flatten2(t: Tensor) -> List[Scalar]:
    assert of_rank(2, t), "Input tensor must be of rank 2"
    return [i for element  in t for i in element]

flatten = ext1(flatten2, 2)
```
用$add1$这个函数举例理解：$r$这个参数反应被拓展函数原本操作的是具体哪一阶的张量，匿名函数`(lambda x: x + 1)`操作对象是标量，因此该函数的r值是0；处理高阶张量的时候是要该张量的元素不是标量，便会调用map函数，也就是把该张量的元素带入匿名函数中。

和$sqr$同理，$zero$函数返回一个阶数和形状相同，但是数值全是零的张，squ返回值是一个所有元素的平方根组成的张量；sum函数原本是处理一阶张量/数组的函数，现在可以处理更高阶的张量; flatten原本是把一个二阶张量/矩阵变成一个一阶张量/数组的函数，现在能让所有高阶张量的阶数减少1。

```python
# 二元操作逻辑相同
def of_ranks(r1: int, r2: int, t1: Tensor, t2: Tensor) -> bool:
    return rank(t1) == r1 and rank(t2) == r2


def ext2(f: Callable, r1: int, r2: int) -> Callable[[Tensor, Tensor], Tensor]:

    def op(t1: Tensor, t2: Tensor) -> Tensor:
        if of_ranks(r1, r2, t1, t2):
            return f(t1, t2)
        else:
            return tmap2(ext2(f, r1, r2), t1, t2)
    return op
```

不过我们对二元操作的拓展要求更高，还希望它能自动按需拓展（也叫**广播（broadcast）**）某个标量，使得上面提到的按元素映射操作成为可能。例如，标量 2 和向量 [1, 2, 3] 相加时，`tadd(2, [1, 2, 3])` 会“广播” 2 到 [2, 2, 2]，结果为 [3, 4, 5]。再如，向量 [1, 2] 加到矩阵 [[1, 1], [2, 2]]，会沿行广播，结果为 [[2, 3], [3, 4]]。

要做到这样可能需要对tmap2做一些修改：
```python
# def tmap2(f: Callable[[Scalar, Scalar], Tensor], t: Tensor, u: Tensor) -> Tensor:
#     if is_scalar(t) and is_scalar(u):
#         return f(t, u)
#     elif is_scalar(t):
#         return [tmap2(f, t, y) for y in u]
#     elif is_scalar(u):
#         return [tmap2(f, x, u) for x in t]
#     else:
#         return [tmap2(f, x, y) for x, y in zip(t, u)]
```
不过这样还是只能拓展标量操作，所以更好的办法是把这一段逻辑写道ext2里面。另外还得处理两个张量阶数不同的情况：
```python
def ext2_broadcast(base_func: Callable, n: int, m: int) -> Callable:

    def g(t: Tensor, u: Tensor) -> Tensor:
        
        rank_t = rank(t)
        rank_u = rank(u)

        if rank_t == n and rank_u == m:
            return base_func(t, u)
        elif rank_t == n:
            return [g(t, sub_u) for sub_u in u]
        elif rank_u == m:
            return [g(sub_t, u) for sub_t in t]
        elif rank_t > rank_u:
            return [g(sub_t, u) for sub_t in t]
        elif rank_u > rank_t:
            return [g(t, sub_u) for sub_u in u]
        else:
            return tmap2(g, t, u)
    return g

tsub = ext2_broadcast((lambda m, n: m - n), 0, 0)
tmul = ext2_broadcast((lambda m, n: m * n), 0, 0)
tadd = ext2_broadcast((lambda m, n: m + n), 0, 0)

def dot1(t: Tensor, u: Tensor) -> Scalar:
    assert of_rank(1, t) and of_rank(1, u), "Both tensors must be of rank 1"
    return sum(tmap2(lambda x, y: x * y, t, u))

dot = ext2_broadcast(dot1, 1, 1)
star = ext2_broadcast(tmul, 2, 1)
# 可以自己找几个例子测试一下
```
这种自动维度对齐机制正是深度学习框架中的广播机制核心原理。有了自动广播的拓展二元操作的函数，就能很容易得到任意两个标量的各种基本的数学操作了。

以上代码逻辑可能会显得比较抽象，可以找几个例子帮助自己理解。

通过递归实现张量操作，我们不仅解决了高维数据处理问题，更深刻理解了函数式编程在科学计算中的强大表现力，希望你已经感受到函数式编程的魅力了。

### 用张量重构训练流程

有了张量这个概念，以及上面这些针对张量的操作函数，我们可以回头看看上一篇文章中遗留下来的问题。

首先我们应该把所有的输入输入输出和参数都用张量来表示，并且使用上面的张量操作，而不是+、—等操作符号：
```python
# 首先很多类型提示都需要从list[float]改成Tensor，例如：
def line(xs: Tensor) -> Callable[[Tensor, Tensor], Tensor]:  
    return lambda w, b: [w * x + b for x in xs]

# 所有针对张量的操作应该使用上面函数替代简单的加减乘除符号，比如l2_loss变成：
def l2_loss(target: Callable[[Tensor], Callable]) -> Callable:
    
    def expectant(xs: Tensor, ys: Tensor) -> Callable:
        
        def objective(theta: list[Tensor]) -> Scalar:
            
            pred_ys = target(xs)(*theta)
            errors = tsub(ys, pred_ys)
            return tsum(sqr(errors)) 
        return objective
    return expectant

# 最主要的是梯度下降：
def gradient_descent(objective_func: Callable[[List[Tensor]], Scalar],
                     initial_theta: List[Tensor],
                     learning_rate: Scalar,
                     num_revisions: int) -> List[Tensor]:
   
    def updata(theta: List[Tensor]) -> List[Tensor]:
        
        gradient = nabla(objective_func, theta)

        # 用tmul和tsub操作张量
        update_step = [tmul(g, learning_rate) for g in gradient]
        revised_theta = tsub(theta, update_step)
        return revised_theta

    return revise(updata, num_revisions, initial_theta)
```
需要注意的是$\theta$的类型提示是List[Tensor]！我在前面说了参数用张量表示，比如在w和b可以分别是一个张量；但是没说参数集本身也是一个张量。之所以这样因为w和b的形状可能是不一样的，虽然我们的自动广播机制可以处理一些把整个参数集的当成张量的操作，不过最好还是使用列表推导式把每一个参数分别传递进去。

最后一个比较麻烦的是nabla函数：
```python
import copy

# 首先需要两个帮助函数，用来获取和修改高阶张量中某个具体值
def get_nested_value(nested_list: Tensor, indices: List[int]):
    """根据索引路径获张量中的值"""
    current = nested_list
    for idx in indices:
        current = current[idx]
    return current

def set_nested_value(nested_list: Tensor, indices: List[int], value: Scalar):
    """根据索引路径设置张量中的值"""
    current = nested_list
    for idx in indices[:-1]:
        current = current[idx]
    current[indices[-1]] = value

def nabla(
    objective_func: Callable[[List[Tensor]], Scalar],
    theta: List[Tensor],
    delta: Scalar = 1e-6
) -> List[Tensor]:
    
    base_loss = objective_func(theta)
    
    # 创建与theta结构相同的梯度容器
    grad_copy = copy.deepcopy(theta)
    
    def update_grad(theta_node: List[Tensor], index_path: List[int] = []):
        
        for i, item in enumerate(theta_node):
            current_path = index_path + [i]
            # print(f"current_path: {current_path}")
            
            # --- Base Case: 如果是标量值 ---
            if is_scalar(item):
                # 创建theta的副本用于计算
                theta_copy = copy.deepcopy(theta)
                
                # 修改theta_copy中对应位置的值
                original_value = get_nested_value(theta_copy, current_path)
                set_nested_value(theta_copy, current_path, original_value + delta)
                
                # 计算新的损失
                new_loss = objective_func(theta_copy)
                
                # 计算梯度并存储到对应位置
                gradient = (new_loss - base_loss) / delta
                set_nested_value(grad_copy, current_path, gradient)
                
            # --- Recursive Step: 如果是列表，递归处理 ---
            else:
                update_grad(item, current_path)
    
    update_grad(theta)
    return grad_copy
```
这里再一次用到了闭包！`update_grad`这个闭包循环地修改grad_copy，直到得到某个参数的完整的梯度。

### Numpy, JAX

因为本文的目的在于演示张量操作，因此没有考虑效率问题，实际操作中使用numpy等库起到加速、避免递归深度限制等问题；对于生产环境的需求（如GPU加速、自动微分），JAX等框架提供工业级解决方案。以下代码显示了如何包装Numpy的操作：
```python

import numpy as np
from typing import Union, List, Tuple
from autograd import grad

# ndarry是Numpy实现的张量对象;再jax中是jax.Array
Tensor = np.ndarray

def is_scalar(x) -> bool:
    return np.isscalar(x) or (isinstance(x, np.ndarray) and x.ndim == 0)


# Numpy.array函数是创建ndarry对象的构造函数
def tensor(*elements) -> Tensor:
    return np.array(elements)

# Numpy中的阶和形状是元数据，可以直接通过对象的ndim和shap属性获取
def rank(t: Union[Tensor, float, int]) -> int:
    return 0 if is_scalar(t) else t.ndim


def shape(t: Union[Tensor, float, int]) -> Tuple[int, ...]:
    return () if is_scalar(t) else t.shape


def tsum(t: Tensor) -> Union[Tensor, float]:
    return t if is_scalar(t) else np.sum(t)


# Ndarray对象实现了__add__和__mul__等方法，因此可以直接使用加号或者星号来得到两个张量的和或者积
def dot(t1: Tensor, t2: Tensor) -> Union[Tensor, float]:
    return np.dot(t1, t2)

# tmap、tmap2、ext1、ext2这些所有函数都只能对应到jax中的一个函数vmap上
# 而且jax.vmap函数还能显式指定展开维度,比我们的实现功能更强大
def tmap(func, *tensors: Tensor) -> Tensor:
    return np.vectorize(func)(*tensors)

    
def flatten(t: Tensor) -> Tensor:
    return t.flatten()

def nablat(
    objective_func: Callable[[List[Tensor]], Scalar],
    theta: List[Tensor],
    delta: Scalar = 1e-6
) -> List[Tensor]:

    # 注意不管是autograd还是jax中的grad函数都是高阶函数，不能当成两个参数一次性传入
    # 还有Autograd 的 grad 无法作用于 List[Tensor]，JAX.grad更通用
    return grad(objective_func)(theta)
```
这里之所以提JAX而不是更常见的Pytorch、TensorFlow等框架是因为JAX也遵循函数式编程范式，学过本系列文章，应该能很快上手。

还需注意使用这些库所带来的速度提升只有在数据量比较大的情况下才能看到。目前为止我们接触的数据量都非常小，所以使用它们不仅不会带来明显的加速，反倒可能会显著减慢运行速度，这点在使用JAX.grad的时候非常明显。
